# «Лучше звоните Борису» — сайт частнопрактикующего юриста

Готовый сайт с собственным сервером. Все заявки с сайта приходят **на компьютер, где запущен сервер**,
и сохраняются в файл `data/requests.db`. Ничего не отправляется во внешние сервисы.

Нужен только **Python 3.8+**, больше ничего устанавливать не надо (https://www.python.org/downloads/ —
на Windows при установке отметьте «Add Python to PATH»).

## Запуск

| Система | Действие |
|---|---|
| Windows | двойной клик по `start.bat` |
| macOS / Linux | `./start.sh` (или `python3 server.py`) |

Откройте http://localhost:8080. В консоли будет напечатан **пароль администратора**
(он также сохраняется в `data/admin_password.txt`). Свой пароль можно задать так:
`BORIS_ADMIN_PASSWORD=мойпароль python3 server.py`.

## Частный домен boris_lawyer

1. Windows: ПКМ по `setup_domain.bat` → «Запуск от имени администратора».
   macOS / Linux: `sudo ./setup_domain.sh` (удалить: `sudo ./setup_domain.sh --remove`).
2. Откройте **http://boris_lawyer:8080** или **http://boris-lawyer.local:8080**.

Чтобы адрес был без `:8080`, запустите сервер на 80-м порту:
`sudo python3 server.py --port 80` (Windows: в консоли администратора `py server.py --port 80`).
Тогда работает просто **http://boris_lawyer**.

Набирайте адрес вместе с `http://`: из-за подчёркивания в имени некоторые браузеры
без него воспринимают `boris_lawyer` как поисковый запрос. Вариант `boris-lawyer.local`
работает в любом браузере.

Домен виден только на этом компьютере. Чтобы сайт открывался с других устройств в вашей
сети, добавьте в их файл hosts строку `<IP этого компьютера> boris_lawyer boris-lawyer.local`
и разрешите порт 8080 в брандмауэре (сервер по умолчанию слушает все сетевые интерфейсы).

## Что работает

- Кнопки «Записаться на консультацию»: форма с выбором даты, времени и формата
  (воскресенье и прошедшие даты недоступны).
- «Заказать обратный звонок» / «Перезвоните мне» / «Срочный выезд».
- «Заказать» / «Обсудить дело» / «Подключить» на каждой цене: форма с уже подставленной услугой.
- «Задать вопрос» на карточках направлений и форма вопроса внизу страницы.
- Меню, мобильное меню, раскрывающиеся FAQ, «Наверх».
- Проверка полей в браузере и на сервере, защита от спам-ботов и ограничение частоты заявок.

## Панель заявок — /admin

http://localhost:8080/admin: список заявок, статусы (новая / в работе / завершена / отклонена),
заметки, поиск, фильтры, удаление и выгрузка в CSV для Excel. Список обновляется
каждые 30 секунд. О каждой новой заявке сервер пишет в консоль и подаёт звуковой сигнал.

## Файлы

```
server.py           сервер (стандартная библиотека Python)
static/             сайт: index.html, styles.css, app.js, admin.*, 404.html
data/               создаётся автоматически: база заявок и пароль (не попадает в git)
start.*             запуск
setup_domain.*      настройка домена boris_lawyer
```

Тексты, цены и факты о Борисе («18 лет практики», «с 2008 года» и т. п.) — примеры:
поправьте их в `static/index.html`, чтобы они соответствовали действительности.
