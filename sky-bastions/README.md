# Небесные Бастионы

Браузерная игра про воздушные крепости. Строите летающий бастион из блоков, сажаете на него экипаж и пробиваетесь через пиратское небо. Экипаж стреляет сам, корабль летит сам, а вы прокачиваете стены, бойцов, баллоны и винты.

Игра собирается в один файл `index.html`. Работает на телефоне (в вертикальной и горизонтальной ориентации) и на компьютере. Прогресс хранится в браузере (localStorage).

## Как запустить

Откройте `index.html` в браузере. Чтобы играть с телефона по ссылке, включите GitHub Pages для репозитория и откройте `.../sky-bastions/`.

## Как устроен код

Исходники лежат в `src/`, из них собирается `index.html`:

```
src/style.css        оформление
src/body.html        разметка экранов
src/js/00-core.js    данные: локации, бойцы, улучшения, цены, колесо, сохранение, платформа (реклама/оплата), звук
src/js/10-draw.js    рисование кораблей, бойцов, баллонов, контейнеров
src/js/20-world.js   параметры кораблей, фон локаций, погода, иконки
src/js/30-hangar.js  ангар, вкладки, карта, колесо, магазин, склад, тестовые окна оплаты и рекламы
src/js/40-battle.js  бой: уровни, враги, оружие, статусы, вторая жизнь, награды
src/js/50-main.js    игровой цикл, кнопки, запуск
```

Правьте файлы в `src/`, затем пересоберите:

```
python3 sky-bastions/build.py
```

Весь баланс (рост урона, цены, награды, сложность) собран в начале `src/js/00-core.js`: функции `GROW`, `COSTF`, `gearCostAt`, `levelReward`, `diffOf` и таблицы `UPG`, `CREW`, `CONT`, `PRODUCTS`, `WHEEL`.

## Что есть в игре

### Уровни
- 6 локаций по 5 уровней: Облачные луга, Песчаный каньон, Ледяные пики, Вулканические острова, Грозовое море, Звёздная высь. У каждой свой фон, погода и пираты.
- 5-й уровень каждой локации — босс: «Чёрный шквал», «Песчаный скорпион», «Ледяной клык», «Огненный кракен», «Повелитель бурь», «Полуночный левиафан».
- 30 уровней образуют круг. Кругов 40, итого **1200 уровней**. С каждым кругом враги сильнее, их больше, у боссов больше баллонов. После 1200-го уровня игра продолжается дальше.
- Карта полётов показывает все круги, звёзды за пройденные уровни и позволяет переиграть любой пройденный уровень.

### Ресурсы
| Ресурс | Где взять | На что тратить |
|---|---|---|
| Монеты | бои, контейнеры, колесо, реклама | все улучшения, найм бойцов |
| Шестерни | контейнеры, боссы, фрегаты, колесо | улучшения с 10-го уровня |
| Алмазы | **только покупка за рубли** | легендарные герои, быстрая прокачка, контейнеры, вращения колеса, вторая жизнь |

Контейнеры: деревянный ящик, стальной контейнер, золотой сундук, небесный ковчег. Выпадают за победы (за босса — золотой, за последнего босса круга — ковчег), из сундуков на шарах, на колесе. Открываются на складе. Внутри монеты и шестерни.

### Экипаж
11 обычных бойцов открываются по ходу игры (Стрелок, Канонир, Гарпунёр, Механик, Тесла-инженер, Снайпер, Ракетчик, Огнемётчик, Морозильщик, Пулемётчик, Щитоносец). Ещё 4 легендарных героя продаются только за алмазы: Капитан Гром, Атлас, Валькирия, Вьюга. У каждого героя есть пассивный бонус или уникальная атака.

### Улучшения
- Стены: стены (8 материалов), гондола, каркас, авторемонт.
- Арсенал: порох (урон всего экипажа), прицелы (скорость стрельбы), добыча (монеты).
- Баллоны: число баллонов (до 6), объём, обшивка (7 тканей), самозаплатка.
- Винты: тяга, подъёмный винт, форсаж, манёвр (уклонение).

Большинство улучшений качаются до 300-го уровня. Если не хватает монет или шестерней, рядом с ценой появляется кнопка **быстрой прокачки за алмазы**: алмазы покрывают только недостающую часть.

### Реклама (только по желанию игрока)
| Где | Что даёт | Лимит |
|---|---|---|
| Экран победы или поражения | ×2 ко всей добыче за бой | за каждый бой |
| Корабль сбит | вторая жизнь (или 20 алмазов) | 1 раз за бой |
| Магазин → «Бесплатно» | немного монет и шестерней | 5 раз в день |
| Кнопка «Бонус» | усиление на 20 минут: +30% урона, +50% монет | 1 раз в день |
| Колесо фортуны | вращение | 2 раза в день после бесплатного |

### Колесо фортуны
1 вращение в день бесплатно, потом 2 за рекламу, потом за 30 алмазов. Два сектора из десяти — легендарные герои (Капитан Гром и Валькирия), шанс каждого 0,3%. Если герой уже есть, вместо него выдаётся небесный ковчег. Все шансы показаны в игре по кнопке «Шансы выпадения».

Шанс легендарного героя маленький, но настоящий. Сектор, который при платном вращении не может выпасть никогда, вводил бы покупателя в заблуждение: магазины приложений такое отклоняют, а закон о защите прав потребителей запрещает вводить в заблуждение о свойствах товара.

## Выпуск в RuStore

Браузерную игру нужно завернуть в Android-приложение с WebView и подключить два SDK:

- **платежи** — RuStore Pay SDK (`ru.rustore.sdk:pay`). Старый BillingClient SDK RuStore больше не развивает;
- **реклама с вознаграждением** — например, Yandex Mobile Ads SDK (формат Rewarded). Для тестов есть демо-блок `demo-rewarded-yandex`.

Без обёртки игра работает в **тестовом режиме**: окна оплаты и рекламы имитируются, деньги не списываются, в магазине висит предупреждение об этом.

### Мост между игрой и Android
Обёртка добавляет в WebView объект `SkyNative` (через `addJavascriptInterface`) с двумя методами:

```kotlin
@JavascriptInterface fun purchase(argsJson: String, callbackId: String)      // {"productId":"gems_420","priceRub":379}
@JavascriptInterface fun showRewarded(argsJson: String, callbackId: String)  // {"placement":"double_reward"}
```

Когда оплата или просмотр завершились, обёртка возвращает результат в игру (из главного потока):

```kotlin
webView.evaluateJavascript("SkyPlatform.resolve('$callbackId', '{\"ok\":true}')", null)
// при отмене или ошибке: {"ok":false,"error":"cancel"}
```

Игра сама начисляет награду только после `{"ok":true}`.

- ID товаров для консоли RuStore: `starter_pack`, `gems_80`, `gems_420`, `gems_900`, `gems_1900`, `gems_5200`, `gems_11500`. Все товары расходуемые (consumable), кроме набора новичка, который продаётся один раз.
- Места показа рекламы (`placement`): `double_reward`, `second_life`, `free_resources`, `daily_power`, `wheel_spin`.

### Что ещё нужно перед релизом
- Проверять покупки на своём сервере через серверный API RuStore и хранить алмазы на сервере. Сейчас всё лежит в localStorage, и подкованный игрок может себе их дописать.
- Указать возрастной рейтинг и в описании приложения упомянуть платные покупки и случайные награды колеса.
- Пройти игру на реальных устройствах и подкрутить баланс поздних кругов: формулы рассчитаны так, чтобы прокачка поспевала за сложностью, но живой баланс на 1200 уровнях нужно проверять игроками.
